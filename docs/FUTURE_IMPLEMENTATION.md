# 后续实现计划

以下记录后续计划及完成状态。未勾选的功能尚未支持；已勾选条目注明完成版本。

- [ ] **尝试在线视频裁剪**：探索 YouTube、Bilibili 等在线视频的可见区域裁剪，包括浏览器视口裁剪；评估实际播放、交互和平台限制。
- [x] **Bilibili 广告切换后恢复观看进度（v1.0.3）**：正常切换广告或隐藏时先静音并暂停，保留播放器与观看位置，切回后手动继续播放；暂停失败或超时则销毁，并在恢复时尝试从保存位置重新加载。已验证真实 B 站视频及异常兜底，保留能力受平台页面兼容性影响。
- [ ] **尝试接入外部小说 App 及漫画**：探索番茄小说等外部阅读平台的接入方式，并考虑漫画阅读支持。
- [x] **支持英文版 App（v1.0.2）**：设置中可选择简体中文或 English，覆盖主窗口、阅读器、视频、托盘、对话框和应用提示，重启后记住选择。
- [ ] **优化广告界面**：改进广告伪装的布局、视觉样式和交互，让界面更自然。
- [x] **广告页面支持时钟、计时器和听歌软件模式（v1.0.4）**：可切换原广告、实时时钟、倒计时／秒表和本地音乐播放器；支持歌单、手动上一首／下一首、播放进度及音量。隐藏、最小化、换模式或切回视频会停止音乐，恢复后手动播放。选择和计时状态本地保存，支持中英文；尚未接入外部音乐服务。
- [ ] **新增模拟软件下载界面**：增加假装正在下载软件的伪装界面，显示模拟进度条、下载速度、剩余时间和软件信息。
- [ ] **适配 macOS**：提供 Mac 版应用，适配窗口、托盘和快捷键行为，并验证 Apple Silicon 与 Intel Mac 的运行和打包。
